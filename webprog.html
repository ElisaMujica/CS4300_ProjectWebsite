1. W3Schools

W3Schools Web Link

This website contains useful information about each coding language. I find it especially helpful for introducing new topics I have not seen before. They provide code examples as well as code exercises to practice what you have learned.

2. LinkedIn Learning

LinkedIn Learning Web Link

This resource is an open online learning website. Here, you can learn just about anything. Lessons are about business, technology, and design. From LinkedIn Learning, not only can you learn niche subjects in depth-- you can also acquire certifications.

3. Youtube

Coding with Mosh

Youtube is a great free way to broaden your skill set. There are many in depth videos that can teach you entire coding languages. Many of the youtubers also provide more sources to learn more, and advice for your web programming career. I recommend Programming with Mosh, his videos are straight forward and have helped me understand concepts.
